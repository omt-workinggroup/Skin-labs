# De Car Guide

One-page website for De Car Guide: honest car buying help in Ghana, with a price guide in cedis.

Static site, no build step. Deploy the folder as-is (Vercel: Framework "Other", no build command, output directory `.`).

- `index.html`: the whole site. Contact details go in the `CONTACT` object near the bottom; car prices are in the `CARS` list just below it.
- `cars/`: car photos from Wikimedia Commons, credited on the page under "Photo credits".
- `og.jpg`: social preview image (1200x630).
