# Skin Lab Stickers

Sticker shop for Skin Lab by Baiden Creatives: browse 966 stickers by category and pack, select and order on WhatsApp, or design your own laptop layout.

Static site, no build step. Deploy the folder as-is (Vercel: Framework "Other", no build command, output directory `.`).

- `index.html` — the whole app
- `data.js` — categories, packs and sticker positions
- `atlas/` — one sprite sheet per pack
